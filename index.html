Bangla Input Setup

Phonetic Bengali (Avro-style) input on Arch Linux and Debian-based systems.

Live site →

Overview

This guide covers setting up Bengali phonetic input using fcitx5 with Bornopata (Avro-style phonetic layout). Works on any desktop environment, including Hyprland, GNOME, KDE, XFCE, and Sway.

1. Install packages

sudo pacman -S fcitx5 fcitx5-configtool fcitx5-m17n m17n-db

Bornopata (Avro phonetic) is available on the AUR:

yay -S bornopata
bornopata-setup

Note: Run bornopata-setup as your regular user, not as root. It adds Bornopata to fcitx5 and restarts the daemon.

Final: Mega one-liner

Copy-paste this entire block to install everything, set shell variables, create the toggle script, bind Ctrl + Space, and make it executable. bornopata-setup configures fcitx5 automatically — no extra clicks needed.

sudo pacman -S --needed fcitx5 fcitx5-configtool fcitx5-m17n m17n-db && yay -S --needed bornopata && bornopata-setup && printf '\nexport GTK_IM_MODULE=fcitx\nexport QT_IM_MODULE=fcitx\nexport XMODIFIERS=@im=fcitx\n' >> ~/.bashrc && printf '\nexport GTK_IM_MODULE=fcitx\nexport QT_IM_MODULE=fcitx\nexport XMODIFIERS=@im=fcitx\n' >> ~/.profile && mkdir -p ~/.local/bin && printf '%s\n' '#!/bin/bash' 'current=$(fcitx5-remote -n 2>/dev/null)' 'if [[ "$current" == "bornopata" ]]; then' '  fcitx5-remote -s keyboard-us 2>/dev/null || fcitx5-remote -c' '  notify-send -i keyboard "Input Method" "Switched to English" -t 2000' 'else' '  fcitx5-remote -s bornopata 2>/dev/null' '  notify-send -i keyboard "Input Method" "Switched to Bangla (Avro)" -t 2000' 'fi' > ~/.local/bin/im-switch && chmod +x ~/.local/bin/im-switch && echo "Done. Log out and back in, then press Ctrl+Space to toggle."

2. Environment variables (all distros)

fcitx5 needs these exported before any graphical apps launch. Add to your shell config:

export GTK_IM_MODULE=fcitx
export QT_IM_MODULE=fcitx
export XMODIFIERS=@im=fcitx

On Hyprland, use hl.env() in your config so the variables reach Wayland clients.

3. Autostart fcitx5

fcitx5 needs to start automatically with your desktop session. Choose your environment:

Hyprland

Add to ~/.config/hypr/hyprland.lua (already included in the Hyprland mega one-liner):

hl.exec_cmd("fcitx5 -d")

Sway

Add to ~/.config/sway/config:

exec fcitx5 -d

GNOME

Open "Startup Applications" and add a new entry:

Name: fcitx5
Command: fcitx5 -d

KDE Plasma

Go to System Settings → Startup and Shutdown → Autostart → Add Program, then enter:

fcitx5 -d

XFCE

Go to Settings → Session and Startup → Application Autostart → Add, then enter:

Name: fcitx5
Command: fcitx5 -d

Any desktop (shell autostart)

Add to ~/.xprofile or ~/.profile:

fcitx5 -d &

After adding autostart, log out and back in for fcitx5 to start automatically.

4. Configure input methods

Run the config GUI:

fcitx5-config-gui
  1. Click the + button to add an input method.
  2. Uncheck "Only Show Current Language".
  3. Search for Bornopata (Arch/AUR) or Bengali › bengali-phonetic (Debian/m17n).
  4. Add it, then move it to the top of the list.

5. Switch between English and Bangla

Default fcitx5 toggle: Ctrl + Space.

Custom toggle with notifications (Hyprland)

Save this as ~/.local/bin/im-switch:

#!/bin/bash
current=$(fcitx5-remote -n 2>/dev/null)

if [[ "$current" == "bornopata" ]]; then
  fcitx5-remote -s keyboard-us 2>/dev/null || fcitx5-remote -c
  notify-send -i keyboard "Input Method" "Switched to English" -t 2000
else
  fcitx5-remote -s bornopata 2>/dev/null
  notify-send -i keyboard "Input Method" "Switched to Bangla (Avro)" -t 2000
fi

Make it executable: chmod +x ~/.local/bin/im-switch

Bind in Hyprland (~/.config/hypr/bindings.lua):

o.bind("CTRL + SPACE", "Toggle Input Method", "/home/ratul/.local/bin/im-switch")

6. Verify

Switch to Bangla (Ctrl + Space), then type:

আমি

If you see আমি, it works. If not:

  • Run fcitx5-diagnose to check for missing pieces.
  • Confirm fcitx5-remote -n shows bornopata when switched.
  • Log out and back in after installing packages.
